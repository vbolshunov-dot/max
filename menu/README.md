Фотографии банного меню.

Бот отправляет их альбомом перед выбором процедур, порядок — по имени файла.
Поддерживаются .jpg, .jpeg, .png, не больше 10 штук.

Положите сюда 1.jpg, 2.jpg, 3.jpg и задеплойте — бот подхватит сам.
Первый гость после деплоя загрузит их в Telegram, дальше они отправляются
мгновенно по file_id.

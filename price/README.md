Листы прайса.

Бот отправляет их по команде /price альбомом, первыми, а сразу за ними —
фотографии из папки `menu`. Порядок — по имени файла.
Поддерживаются .jpg, .jpeg, .png; в альбом Telegram берёт не больше 10 фото
на оба каталога вместе.

Поменяли цены — положите сюда новый файл вместо старого и задеплойте.
После этого один раз отправьте боту /price: старый альбом закэширован по
file_id, и обновится он только после сброса кэша (перезапуск с новой
персистентностью) — либо удалите ключ `price_file_ids` из файла состояния.
